Requirements, backlog, tests and defects of a product, in one place.

Nexmap is a server with a web UI and a REST API, and a command line client that connects repositories, CI pipelines and AI agents to it.

Sign in Read the documentation

Install the CLI

Linux and macOS

curl -fsSL https://nexmap.net/install.sh | sh

Windows (PowerShell)

irm https://nexmap.net/install.ps1 | iex

The scripts verify the download against the release's checksums. To pin a version, set NEXMAP_VERSION, e.g. v1.0.0. Archives for every platform are under Downloads; then see Setting up the CLI.
